# QBonita App 🛍️

Aplicativo mobile para loja de papelaria e presentes desenvolvido com Flutter, Spring Boot e MySQL.

## 📱 Sobre o projeto

O QBonita App foi criado como projeto de estudos com foco em arquitetura mobile moderna utilizando Flutter no frontend e Java Spring Boot no backend.

O sistema possui:
- catálogo de produtos
- categorias
- painel administrativo
- autenticação JWT
- integração com API REST
- banco MySQL
- navegação mobile moderna

---

## 🚀 Tecnologias utilizadas

### Frontend
- Flutter
- Dart

### Backend
- Java 17
- Spring Boot
- Spring Security
- JWT
- Maven

### Banco de dados
- MySQL 8

## ⚙️ Como executar o projeto

### Backend

```bash
cd backend
mvn spring-boot:run
```

### Frontend

```bash
cd frontend
flutter pub get
flutter run
```
